# 🔑 Interactive Login Page UI

> A modern, responsive, and clean Login Card interface designed with pure HTML5 and custom CSS3.

---

### 🎨 Preview & Features

- **Form Fields:** Custom Email Address and Password input fields with validation (`required`).
- **User Experience:** Includes a "Remember me" checkbox, "Forgot password?" link, and a signup redirection option.
- **Responsive Layout:** Designed inside a `.login-card` container for smooth adaptability across mobile and desktop screens.
- **Clean Structure:** Built with semantic HTML elements and modular CSS architecture.

---

### 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (`style.css`)
- **Code Editor:** Visual Studio Code
